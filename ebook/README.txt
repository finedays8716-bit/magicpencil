EBOOK 폴더 사용법
1. ebook 폴더를 magicpencil GitHub 저장소 루트에 그대로 업로드합니다.
2. /ebook/ 주소로 접속합니다.
3. 그림 추가 → 글자/말풍선 편집 → '완성된 E북 보기'로 확인합니다.
4. ending.png는 마지막 고정 페이지 그림입니다.

현재 버전은 편집 데이터를 브라우저 localStorage에 저장합니다.
따라서 같은 기기/브라우저에서는 유지되지만, 다른 기기에 URL만 보내면 편집한 작품 데이터까지 공유되지는 않습니다.
다른 기기 공유 기능은 다음 단계에서 서버 저장 기능을 연결해야 합니다.
