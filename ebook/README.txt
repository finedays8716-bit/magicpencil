v17 - PDF 없이 이미지 페이지 방식

1) ebook/index.html을 이 버전으로 교체합니다.
2) 기존 ebook/images 폴더는 그대로 사용합니다.
3) 편집기에서 E북을 완성합니다.
4) '📦 학부모용 E북 만들기'를 누릅니다.
5) parent-ebook.zip이 생성됩니다.
6) ZIP을 풀면:
   index.html
   pages/page-01.jpg, page-02.jpg ...
   README.txt
7) GitHub ebook/view/에 index.html과 pages 폴더를 올립니다.
8) 기존 book.pdf는 삭제해도 되고 남겨도 뷰어에는 영향이 없습니다.

학부모 뷰어:
- 외부 PDF 라이브러리 없음
- PC 이전/다음
- 모바일 좌우 스와이프
- 페이지 전환 효과
- 처음으로 버튼 없음
